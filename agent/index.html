01

チャットのAIと何が違う？

同じことを頼んで、動き方を比べてみます。頼むのは「過去の投稿をもとに、来週のリール台本を3本」。

  1. 自分過去の投稿を探して、コピーして貼る
  2. 自分「この口調で」と毎回説明する
  3. AI台本を3本、画面に書く
  4. 自分コピーしてメモに保存。直す
  5. 自分次の週も、また貼って説明するところから
手を動かすのはほとんど自分。
  1. 自分「postsフォルダを見て、私の口調で3本」と頼む
  2. AIフォルダを自分で開いて、過去の投稿を読む
  3. AI口調のクセを整理して、台本を3本書く
  4. AIファイルに保存して「できました」と返す
  5. 自分読んで、直したいところを伝える
自分がやるのは、頼むのと最後に直すところ。

チャットのAIは、聞かれたことに答えるところまで。エージェントはゴールを渡すと手順を自分で考えて、ファイルを開いたり保存したりしながら最後までやってくれます。Claudeを作ってるAnthropicも、エージェントは「進め方と道具の使い方を、AIが自分で決めて動くもの」って説明してます。

出典：Anthropic「Building effective agents」（2024-12-19）

02

Claude Code・Codex・Muse

名前はよく聞くけど、違いがわかりにくい3つ。どれもいチが毎日使ってます。

03

発信者がAIにまかせてること

気になるものをタップすると、中身とプロンプトが開きます。プロンプトは右上のボタンでそのままコピーできます。

過去の投稿から、自分の口調で台本の下書きClaude CodeCodex

最初に試すならこれ。過去のキャプションや台本をテキストにして1つのフォルダに入れておくと、AIが自分で読みにいきます。毎回「この口調で」って説明しなくて大丈夫。

プロンプト
postsフォルダの過去投稿を全部読んで、私の口調の特徴を10個にまとめて。そのあと、そのルールで「〇〇」の60秒台本を3案書いて、draftsフォルダに保存して。
冒頭の1行を20案出して、強い順に並べるClaude CodeCodex

最初の1行は、いちばん悩むところ。自分で3つ考えるより、20案から選ぶ方が早いです。理由もつけてもらうと、どれを選ぶか自分で決める練習にもなる。

プロンプト
この台本の冒頭1行目の案を20個出して。弱い順に並べて、上位3つを残す理由も書いて。
口調のルールを「スキル」にして、毎回チェックClaude Code

スキルはAIに渡す作業の手順書。一度作っておくと、次からは名前を呼ぶと同じ基準で見てくれます。Anthropicのマーケのチームも、ブランドの口調をスキルにして確認に使ってるそうです。

プロンプト
私の口調ルールをスキルにして。次から台本を書いたら、このスキルで言い回しをチェックして直して。

出典：How Anthropic uses Claude in Marketing

言い過ぎ・根拠のない数字にしるしをつける係Claude CodeCodex

投稿前の最後の見直し。「誰でも」「必ず」みたいな言い過ぎや、出どころのない数字を拾ってもらいます。直すかどうかは自分で決めます。

プロンプト
この投稿文を読んで、言い過ぎ・根拠のない数字・誤解されそうな表現にしるしをつけて、言い換え案を出して。
メモの山から、来週のネタ候補を5つClaude CodeCodex

スマホのメモやObsidianにたまったものを、AIに読ませて整理します。元のメモへのリンクもつけてもらうと、あとで探し直さなくていい。

プロンプト
メモフォルダを見て、似たメモをまとめて、来週のネタ候補を5つ、元のメモのリンクつきで一覧にして。
毎朝7時に、AIニュースとネタ案が届くClaude Code

定期タスクにしておくと、寝てる間に調べてくれます。出典のURLもつけてもらうと、そのまま裏取りに使えます。いチも毎朝これを読むところから始めてます。

プロンプト
毎朝7時に、AIの新しいニュースを3つ調べて、発信のネタ案と出典URLつきで news.md に追記する定期タスクを作って。
カット編集：文字起こしから「切る所の一覧」を作るClaude CodeCodex

編集はまずここから。言い間違い・言い直し・長い間・同じ話のくり返しを、AIに時間つきで一覧にしてもらいます。切るのはいつもの編集アプリで、自分の手で。どこを残すかは自分で決めます。

文字起こしの渡し方は2通りあります。

A. 動画ごとAIに渡す
videosフォルダの動画を文字起こしして、時間つきで書き出して。そのあと、言い間違い・言い直し・長い間・同じ話のくり返しを探して、切る所の一覧を「開始〜終了・何を切るか・理由」の表にして。迷う所は切らずに「迷い」と印をつけて。
B. 編集アプリの自動字幕を渡す
この字幕ファイル（自動字幕を書き出したもの）を読んで、言い間違い・言い直し・長い間・同じ話のくり返しを探して、切る所の一覧を「開始〜終了・何を切るか・理由」の表にして。迷う所は切らずに「迷い」と印をつけて。

Aは、文字起こしの準備からAIが進めます。Bは、CapCutのパソコン版などで自動字幕を字幕ファイルとして書き出してから渡します。書き出せるかどうかは、アプリや版によって違います。

テロップ入れ：台本から字幕ファイル（SRT）を作るClaude CodeCodex

カットが終わったら次はテロップ。CapCut・Premiere・DaVinci Resolveに読み込める字幕ファイルを、台本から作ります。テロップを1行ずつ打たなくてよくなる。編集アプリには、アプリの「読み込み」から入れます。

プロンプト
この台本を、1行が短めの字幕ファイル（SRT）にして。読み上げの速さは1秒7文字くらいで時間を割り振って。
Claude CodeとCodexを、同じフォルダで交互にClaude CodeCodex

どちらも AGENTS.md って指示書を読めるので、ルールを1枚にまとめておくと、どっちに頼んでも同じ前提で続きからやってくれます。片方が上限に当たっても止まらない。

プロンプト
このフォルダの作業ルールを AGENTS.md にまとめて。目的・置き場所・やってはいけないこと・終わったら書く引き継ぎメモの書き方を入れて。
外出先から、スマホで続きを頼むClaude Code

家のパソコンで動いているClaude Codeに、スマホから話しかけて続きを頼めます（Remote Control）。移動中に台本を進めてもらって、帰ってから確認して仕上げます。

出典：Claude Code 公式ドキュメント

パスワードやAPIキーは、AIとのチャットに貼らない。設定ファイルに自分で書いて、AIには「書いたよ」って伝えれば動きます。

04

MuseとClaude Codeを組み合わせる

Museはインスタのことを聞く係、Claude Codeはパソコンの中で書いて保存する係。Museに聞いた答えをClaude Codeに渡して、台本にしてもらいます。

① Museに聞く直近30日で反応がよかった投稿と、その共通点
② 答えを貼るMuseの答えをコピーして、Claude Codeに渡す
③ Claude Codeが書く次の3本の企画と台本を、フォルダに保存
① Museへ
私のインスタの直近30日で反応がよかった投稿を3つ挙げて、共通点を教えて。
③ Claude Codeへ（Museの答えの下に）
この分析をもとに、次の3本の企画と台本の下書きを作って、ideasフォルダに保存して。

公式の連携機能ではなく、コピーで受け渡す使い方です。Museでインスタの数字を聞くには、プロアカウント（ビジネス・クリエイター）が前提になります。

05

最初にやること

終わったらチェックを入れておくと、このスマホに残ります。

  • まかせたい作業を1つ決める

    毎週やっていて、手順がだいたい同じもの。台本の下書き・キャプション・ネタ出しあたりが始めやすいです。

  • 材料を1つのフォルダにまとめる

    過去の投稿・台本・メモをテキストで。ここがないと、AIは何も読みにいけません。

  • 03のプロンプトを1つ、そのまま投げる

    Claude CodeかCodexに。最初からうまくいかなくても大丈夫です。止まったところは、下のLINEで聞いてもらえたら返します。

止まったら、LINEで続きを返します

最初の1回は、フォルダの場所やプロンプトの頼み方でつまずきがちです。どれを試して、どこで止まったかを送ってもらえたら、その続きのやり方をいチが返します。「台本のやつ、フォルダが見つからないで止まった」くらいで大丈夫。
もらった内容は、次にLINEで送るものを決めるのに使います。

LINEで送る
