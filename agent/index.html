01

チャットのAIと、何が違う？

同じお願いをしたときの動き方を比べると、違いがいちばんわかりやすいです。お願いは「過去の投稿をもとに、来週のリール台本を3本」。

  1. 自分過去の投稿を探して、コピーして貼る
  2. 自分「この口調で」と毎回説明する
  3. AI台本を3本、画面に書く
  4. 自分コピーしてメモに保存。直す
  5. 自分次の週も、また貼って説明するところから
手を動かすのは、ほとんど自分。
  1. 自分「postsフォルダを見て、私の口調で3本」と頼む
  2. AIフォルダを自分で開いて、過去の投稿を読む
  3. AI口調のクセを整理して、台本を3本書く
  4. AIファイルに保存して「できました」と返す
  5. 自分読んで、直したいところを伝える
自分の仕事は、頼むことと仕上げること。

チャットのAIは「答える係」。エージェントは、ゴールを渡すと自分で手順を考えて、ファイルや道具を動かしながら最後までやる係です。Claudeを作っているAnthropicも、エージェントを「進め方と道具の使い方を、AIが自分で決めて動くもの」と説明しています。

出典：Anthropic「Building effective agents」（2024-12-19）

02

Claude Code・Codex・Muse

名前はよく聞くけど、何がどう違うのか。いち自身が毎日使っている3つを並べました。

パソコンの中で動く、いちばんの働き手

Anthropicのエージェント。パソコンのファイルを読んで書き換え、コマンドを動かし、ほかのサービスともつながります。いちの台本・編集の下ごしらえ・経理・このLINEの準備まで、ほぼ全部ここから。

使う場所
デスクトップアプリ（Mac／Windows）・ターミナル・VS Codeなど・Web・スマホアプリ
覚えさせ方
CLAUDE.md（毎回読む指示書）／スキル（作業の手順書）／メモリ
つながる先
MCPでGmail・Googleカレンダー・スプレッドシートなど
決まった時間に
定期タスクで「毎朝7時にこれ」もできる
プラン
有料のPro（月20ドル）から。Freeには入っていない

出典：Claude Code 公式ドキュメント・料金ページ（2026-10-28時点・米ドル）

ChatGPTの会社が作った、もう1人の働き手

OpenAIのエージェント。Claude Codeと同じように、ファイルを調べて書き換え、コマンドを動かします。いちはClaude Codeと同じフォルダで交互に使っていて、片方が混んでいるときも手が止まりません。

使う場所

出典：Codex 公式ドキュメント・料金（2026-10-28時点・米ドル）

スマホで聞ける、インスタ担当

Metaのエージェント。2026年10月23日に日本でも使えるようになりました。インスタ・Facebook・Threadsと同じアカウントでつながるので、自分のインスタのことを話しかけて聞けます。いちは「インスタの数字とリサーチの担当」として使っています。

使う場所
スマホアプリ（iOS・Android）・Web
つながる先
Instagram・Gmail・Googleカレンダーなど
安全面
メール送信などの大事な操作の前は、本人に確認してから動く
料金

日本のスマホ版・Web版は、パソコンの中のファイルは扱いません。ファイルの作業はClaude CodeやCodexの出番です。

03

発信者が、AIにまかせていること

気になるものをタップすると、中身とお願い文が出てきます。お願い文は、右上のボタンでそのままコピーできます。

過去の投稿から、自分の口調で台本の下書きClaude CodeCodex

いちばん最初に試してほしいもの。過去のキャプションや台本をテキストで1つのフォルダにまとめておくと、AIが自分で読みにいきます。毎回「この口調で」と説明しなくて済みます。

お願い文
postsフォルダの過去投稿を全部読んで、私の口調の特徴を10個にまとめて。そのあと、そのルールで「〇〇」の60秒台本を3案書いて、draftsフォルダに保存して。
冒頭の1行を20案出して、強い順に並べるClaude CodeCodex

伸びるかどうかは最初の1行で決まりがち。自分で3つ考えるより、20案から選ぶ方が早いです。理由つきで並べさせると、自分の判断の練習にもなります。

お願い文
この台本の冒頭1行目の案を20個出して。弱い順に並べて、上位3つを残す理由も書いて。
口調のルールを「スキル」にして、毎回チェックClaude Code

スキルは、AIに渡す作業の手順書。一度作れば、次からは名前を呼べば同じ基準で見てくれます。Anthropicのマーケ担当も、ブランドの口調をスキルにして確認に使っています。

お願い文
私の口調ルールをスキルにして。次から台本を書いたら、このスキルで言い回しをチェックして直して。

出典：How Anthropic uses Claude in Marketing

言い過ぎ・根拠のない数字にしるしをつける係Claude CodeCodex

投稿前の最後の見直し。「誰でも」「必ず」みたいな言い過ぎや、出どころのない数字を拾ってもらいます。直すかどうかは自分で決めます。

お願い文
この投稿文を読んで、言い過ぎ・根拠のない数字・誤解されそうな表現にしるしをつけて、言い換え案を出して。
メモの山から、来週のネタ候補を5つClaude CodeCodex

スマホのメモやObsidianにたまったものを、AIに読ませて整理。元のメモへのリンクつきで出させると、あとで探し直さなくて済みます。

お願い文
メモフォルダを見て、似たメモをまとめて、来週のネタ候補を5つ、元のメモのリンクつきで一覧にして。
毎朝7時に、AIニュースとネタ案が届くClaude Code

定期タスクにしておくと、自分が寝ている間に調べてくれます。出典のURLもつけさせると、そのまま裏取りに使えます。いちも毎朝これで1日が始まります。

お願い文
毎朝7時に、AIの新しいニュースを3つ調べて、発信のネタ案と出典URLつきで news.md に追記する定期タスクを作って。
台本から字幕ファイル（SRT）を作るClaude CodeCodex

CapCut・Premiere・DaVinci Resolveに読み込める字幕ファイルを、台本から作ります。テロップを1行ずつ打つ時間がなくなります。編集アプリには、正式な「読み込み」で入れるのが安心です。

お願い文
この台本を、1行が短めの字幕ファイル（SRT）にして。読み上げの速さは1秒7文字くらいで時間を割り振って。
Claude CodeとCodexを、同じフォルダで交互にClaude CodeCodex

どちらも AGENTS.md という指示書を読めるので、ルールを1枚に書いておけば、どちらに頼んでも同じ前提で続きから動きます。片方の上限に当たっても止まりません。

お願い文
このフォルダの作業ルールを AGENTS.md にまとめて。目的・置き場所・やってはいけないこと・終わったら書く引き継ぎメモの書き方を入れて。
外出先から、スマホで続きを頼むClaude Code

家のパソコンで動いているClaude Codeに、スマホから話しかけて続きを頼めます（Remote Control）。移動中に台本を進めてもらって、帰ったら確認して仕上げ。

出典：Claude Code 公式ドキュメント

パスワードやAPIキーは、AIとのチャットに貼らないのが基本です。設定ファイルに自分で書いて、AIには「書いた」と伝えます。

04

Muse × Claude Code の組み合わせ

Museはインスタのことを聞ける係、Claude Codeはパソコンの中で書いて残す係。役割を分けると、それぞれの得意なところを活かせます。

① Museに聞く直近30日で反応がよかった投稿と、その共通点
② 答えを貼るMuseの答えをコピーして、Claude Codeに渡す
③ Claude Codeが書く次の3本の企画と台本を、フォルダに保存
① Museへ
私のインスタの直近30日で反応がよかった投稿を3つ挙げて、共通点を教えて。
③ Claude Codeへ（Museの答えの下に）
この分析をもとに、次の3本の企画と台本の下書きを作って、ideasフォルダに保存して。

公式の連携機能ではなく、コピーで受け渡す使い方です。Museでインスタの数字を聞くには、プロアカウント（ビジネス・クリエイター）が前提になります。

05

今日やる3つ

終わったらチェック。このスマホに残るので、続きからできます。

  • まかせたい作業を1つ決める

    毎週やっていて、手順がだいたい同じもの。台本の下書き・キャプション・ネタ出しあたりが始めやすいです。

  • 材料を1つのフォルダにまとめる

    過去の投稿・台本・メモをテキストで。AIが読みにいける場所を作るのが、エージェントの第一歩です。

  • 03のお願い文を1つ、そのまま投げる

    Claude CodeかCodexに。うまくいかなくても大丈夫。どこで止まったかが、次の材料になります。

どれを試したか、LINEで一言

「1つ目の台本やった」くらいで大丈夫です。どこまで進んだかを見て、次の使い方をいちが返します。
