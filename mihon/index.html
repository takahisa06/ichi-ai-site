台本の渡し方3つ
AIの台本を、自分で直さなくていいように

台本を頼むときの
渡し方3つ

AIの台本がしっくりこないのは、指示が短いからではなく、渡しているものが足りないからです。見本・合格ライン・説明書の3つを埋めると、そのままコピペできる頼み方ができます。

  • 01説明書（1回だけ作る）
  • 02見本と合格ライン（毎回の頼み方）
  • 03説明書を入れる場所
  • 04伸びた投稿がまだ無いとき
  • 05できた台本を送る
01

説明書（1回だけ作る）

毎回書いている自己紹介を、1回まとめます。入れた言葉が下の説明書に入ります。

説明書

見本：前に伸びた自分の投稿を1本貼る

03

  
説明書を入れる場所

  
一度入れておくと、そのプロジェクトの中の会話では毎回読まれます。もう自己紹介から書かなくて大丈夫です。

  
    
    
  1. ChatGPTプロジェクトを作る →「…」→ プロジェクト設定 → 指示に貼る
    2. 
    
  2. Claudeプロジェクトを作る →「プロジェクトの指示を設定」に貼る（有料プラン）
    3. 
    
  3. Claude Code作業フォルダの CLAUDE.md に書く（/init で最初の1枚が作れます）
    4. 
  

  
出典：Projects in ChatGPT／Claude プロジェクトの作り方／Claude Code コマンド一覧（2026年11月確認）





  
04

  
伸びた投稿がまだ無いとき

  
好きな発信者の投稿を見本にするときは、文章ではなく組み立てだけを渡します（最初の一言・話の順番・最後の呼びかけ）。文章をそのまま貼って似せると、あなたらしさが消えて、丸写しにもなります。





  
05

  
できた台本を送る

  
この渡し方で作った台本をLINEで送ってもらえたら、いチが一言返します。

  
LINEで送る「台本の相談：」と入った状態で開きます

  
スマホのLINEで開きます（パソコン版のLINEでは開きません）。




AIが書いた台本は、最後に自分の声で読んでから使ってください。
