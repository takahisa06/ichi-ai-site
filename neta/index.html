ネタ出しの頼み方
そのままコピペできる3つ

ネタ切れの日、私は自分で考えません。AI社員に自分の数字を出してもらい、伸びている人の型と比べて、差が出たところだけをネタにします。その時の頼み方を、そのまま使える形にしました。

  • 01自分のジャンルを入れる
  • 02頼み方3つ（コピーして使う）
  • 03私が数字を見る順番
  • 04やってみた結果を送る
01

自分のジャンルを入れる

入れた言葉が、下の頼み方にそのまま入ります。

02

頼み方3つ

1と2は Muse に、3は Muse でも Claude Code でも大丈夫です。順番どおりに頼みます。

03

私が数字を見る順番

再生数だけを見ると、ネタを外します。私はこの順番で見ています。

  1. コメントがついた投稿何の話にコメントがついたか。私の場合は、仕組みの話にだけついていました
  2. 保存された投稿あとで見返したい中身だったか
  3. シェアされた投稿人に教えたくなる話だったか
  4. 再生数最後に見ます。入口の強さの目安です
04

やってみた結果を送る

出てきたネタを一言LINEで送ってもらえたら、いチが感想を返します。送ってもらった内容で、次に作る資料も決めています。

LINEで送る「ネタの相談：」と入った状態で開きます

スマホのLINEで開きます（パソコン版のLINEでは開きません）。

AIが出した数字や型は、最後に自分の目で確かめてから使ってください。
