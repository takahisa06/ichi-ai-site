AI 任せる前に読むページ

AIに渡している禁止リスト

AIは頭が良くなるほど、頼まれたゴールに向かってなんとかしようとします。明らかにアウトならやめるけど、グレーな方法だとそのまま進んじゃう。やらせている側も気づかない。なので、止めるルールは人間が先に決めて、AIに毎回読ませています。

規約で禁止 はっきり書かれていない（グレー）

00止め方の考え方は3つだけ

細かいルールより先に、この3つを決めておくと迷わないです。

  1. 使っていい入口を、先に人間が決める公式の API・公式の機能・アプリの正式な読み込み。ここ以外は通らせない
  2. 最後のボタンは、自分で押す投稿・送信・購入・申込。AIは下書きと準備まで
  3. 禁止リストを、AIに毎回先に読ませる下のリストをそのままコピーして使えます

01サービスごとの禁止リスト

どれも規約の原文を確認しています（2026年10月31日時点）。✕がAIにやらせないこと、○が代わりのやり方です。

インスタ・Threads

規約で禁止

✕ログインしたままのブラウザを、AIに開かせて数字を集める

✕AIにブラウザでいいね・フォロー・投稿をさせる

○数字は公式の入口（Meta の API）か、Meta 自身の AI の Muse で

○投稿の最後のボタンは自分で押す

根拠: Meta 自動データ収集規約「書面の許可なく、自動の方法でデータを集めない」（ボット・スクレイパー等）＋インスタ利用規約／2024-10-07 施行 原文

TikTok

規約で禁止

✕AIにブラウザで TikTok を開かせて、数字を集める・操作する

○数字は TikTok の公式 API か、自分の目で

根拠: 利用規約 第5条「自動のスクリプトで情報を集める、または本サービスとやりとりする」行為を禁止／2025-12-01 更新 原文

CapCut

規約で禁止

✕AIに CapCut を操作させる

✕CapCut のプロジェクトファイルを AI に解析させて、中身を書き換える

○AIが作るのは、読み込めるふつうのファイル（カット済みの動画・字幕 SRT）まで

○パソコン版の CapCut で、自分で読み込む

根拠: 利用規約 第6条 9号（自動のスクリプト等で情報を集める・やりとりする）／2号（解読・改変・リバースエンジニアリング・派生物の作成）／2026-04-15 更新 原文

楽天ROOM

規約で禁止

✕AIやプログラムに「コレ!」投稿・コメント・いいね・フォローをさせる

○AIは商品さがし（楽天の公式 API）と紹介文の下書きまで

○投稿は自分の指で

根拠: ROOM 利用規約 第11条1項4号「スクリプトその他のプログラムを実行する等の方法により、機械的に投稿、コメント等をする行為」。第12条で、予告なく投稿の削除・利用停止・成果報酬の取消・楽天会員資格の停止まで／2026-08-18 改定 原文

楽天アフィリエイト

規約で禁止

✕自動ツールでの投稿・自分の投稿のリポストのくり返し

✕DM・LINE・メールでアフィリンクを送る（自動でも手でも）

✕ブラウザの拡張機能で楽天のページに情報を出す

○リンクは誰でも見られる場所に、自分で貼る

根拠: 楽天アフィリエイト事務局「SNS利用の際の注意喚起」（2026-02-25）＝自動ツール等による投稿はスパムとして利用停止 お知らせ／ガイドライン（2025-06-26 更新）＝予告なく利用停止・報酬の返金請求 原文

02AIにそのまま渡せる禁止リスト

Claude Code なら CLAUDE.md、ChatGPT ならカスタム指示、Muse なら最初の会話に貼っておきます。

コピーして貼る【やってはいけないこと（毎回最初に読む）】 - インスタ・Threads・TikTok・楽天を、ログインしたブラウザで自動で動かさない（開く・読む・押す・投稿する、全部） - 数字や商品は、公式の API か公式の機能からだけ取る - CapCut など編集アプリの中身（プロジェクトファイル）は書き換えない。作るのは読み込めるファイル（動画・字幕・XML）まで - 楽天ROOMの投稿・コメント・いいね・フォローはしない（下書きまで） - アフィリンクを DM・LINE・メールで送らない - 投稿・送信・購入・申込の最後のボタンは押さない。人に渡す - 規約がはっきりしない操作は、始める前に止まって聞く

03規約に沿った動画編集の流れ

AIで編集を楽にしたいときも、アプリの中をAIに触らせなければ規約の範囲で進められます。全体の形はこうです。

AIカット・字幕を考える
→
ファイル動画・字幕・XML
→
アプリ正式に読み込む

AIが作るのは「アプリが正式に読み込めるふつうのファイル」まで。読み込んだあとの仕上げと書き出しは、自分でアプリを触ります。Premiere・After Effects・DaVinci Resolve のように、メーカーが外からつなぐ入口を公開しているアプリなら、その入口を使います。

04自分のアプリだと、どこまで任せていい？

ここまで読めば、「AIにやらせないこと」と全体の形は押さえられる。でも実際に手を動かすと、だいたい次の所で止まります。

  • CapCutで作ってきたけど、アプリを替えたほうがいいの？
  • 字幕のファイルって、どのアプリにどう読み込むの？
  • そもそも、自分のパソコンで動くの？

答えは、使っているアプリ、パソコンかスマホか、週に何本作るかで変わります。同じ答えを全員に配れないので、ひとりずつ聞いて決める形にしました。
